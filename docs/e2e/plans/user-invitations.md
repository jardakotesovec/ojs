# User invitations

- **Area:** 5. Users, roles & access
- **Placement:** lib/pkp
- **Budget:** 6 tests
- **Absorbs:** lib/pkp/playwright/tests/user-invitation.spec.js (rows 1, 3, 4, 5 — 4 tests); lib/pkp/playwright/tests/user-role-assignment.spec.js (rows 2, 6 — 2 tests)
- **Scenario needs:** journal scenario `users[]` (scratch journal; dbarnes as manager; **throwaway invitees created via `users[]` + `password`** — refit done, phudson no longer seeded and no pending invitation accumulates on shared users). Mailpit with **scoped reads only**: `pkpMail.find({to, contains: tag})` — the tag reaches the body via `{$contextName}`; `latestTo`/`inboxFor` are unscoped in practice (Mailpit's `/api/v1/messages` ignores its `query` param, verified v1.29.7) and the absorbed spec's `clearAll()` calls were removed on refit (principle 8). Accept/decline URLs extracted via the spec-local single-quoted-anchor helper (`btn-accept`/`btn-decline`). Rows 3–5 create their invitation through the same REST pipeline the wizard drives (`invitations/add → populate → invite`, manager session + CSRF) per principle 4 — note the populate must carry `emailComposer: {subject, body}` from the default `USER_ROLE_ASSIGNMENT_INVITATION` template, else the email body is empty (app bug in `UserRoleAssignmentInvite::getMailable()`, see ledger). Invitation wizard shapes verified in the absorbed specs: search → details → email composer (manager side); userCreate → userDetails → review (invitee side); Edit-user wizard skips the search step; an EXISTING-user invitation collapses the accept wizard to the single review step, and the receive API auto-authenticates server-side per request (the browser may still bounce through /login afterwards — row 3 tolerates both landings).
- **Round 2 / out of scope:**
  - ORCID step inside the accept wizard (covered by `orcid` plan).
  - Reviewer invitations issued from the review workflow (covered by `reviewer-assignment` / `reviewer-response`).
  - Invitation expiry by date (no deterministic in-test clock; revisit with a time-travel hook if one lands).
