# Journal homepage

- **Area:** 4. Reader front end
- **Placement:** ojs
- **Budget:** 5 tests
- **Absorbs:** playwright/tests/journal-homepage.spec.js (index test only; its archive test is absorbed by issue-archive-toc)
- **Scenario needs:** submission-published fixture; journal scenario (`users`, `issues`, `enableAnnouncements` passthrough). Announcement content and sidebar/theme configuration are journal-level mutations → scratch journal, seeded via UI (one-off states). `publications[].metadata.datePublished` passthrough: **landed in wave 1** (PublicationsProcessor METADATA_FIELDS, lib/pkp/classes/testing/scenario/Processor/PublicationsProcessor.php:52; documented in skill scenarios.md — `metadata.datePublished` survives `published: true`). No open gaps. Note for row 4: the homepage recent-published listing actually orders by `submissions.date_submitted` DESC (IndexHandler never sets `orderBy`, collector default — lib/pkp/classes/submission/Collector.php:61), not `date_published`; the spec seeds older-datePublished first so seed order and datePublished order agree.
- **Round 2 / out of scope:**
  - Homepage image upload + additional homepage content (website-appearance feature owns appearance forms).
  - Highlights carousel (separate management UI, low usage).
  - Category listing content organization on homepage (`JournalContentOption::CATEGORY_LISTING`) — see browse-category-section round 2.
  - Pagination of the recent-publications listing.
