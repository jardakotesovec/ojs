## Gaps
- Several concrete/base handler classes referenced by subclasses in scope now live under `lib/pkp/classes/controllers/` (PSR-4 migration target), e.g. `GridHandler`, `CategoryGridHandler`, `PluginGridHandler`, `ListbuilderHandler`, `PKPReviewerGridHandler` — out of declared scope (`controllers/`, `lib/pkp/controllers/`) so not atomized here; `ReviewerGridHandler` (controllers/grid/users/reviewer) has an empty op list because all ops are declared on its out-of-scope parent `PKPReviewerGridHandler`.
